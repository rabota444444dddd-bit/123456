ЦКС — Робочий офіс (інтерфейс за макетом Frame 6)

Файли:
index.html  — каркас сторінки
style.css   — всі кольори, шрифти, розміри (палітра на початку файлу)
app.js      — уся логіка програми (інтерфейс українською)
Img/        — ваші іконки: логотип, пошук, експорт, редагування, видалення,
              трикрапки, трикутник, кнопка бічної панелі, вікно вибору опцій

Запуск: тримайте index.html, style.css, app.js і папку Img в одній папці
та відкрийте index.html у браузері.
Для шрифту Roboto та вигрузки в .xlsx потрібен інтернет.
Дані зберігаються в браузері (localStorage), спільного сервера поки немає.
